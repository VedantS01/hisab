# Hisab Initial Build Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Hisab end-to-end minus the four real-format parsers (blocked on sample files): HisabCore domain package with full tests, branding assets, and the SwiftUI/SwiftData app with dashboard, coverage grid, import flow, transactions, reconciliation, and settings.

**Architecture:** Two-layer split. `HisabCore` is a pure-Swift package (Foundation + CryptoKit only) holding all domain logic as value types and pure functions, TDD'd via `swift test` on macOS. The `Hisab` iOS app (SwiftUI + SwiftData, project generated by xcodegen) wraps core types in persistence models and thin views.

**Tech Stack:** Swift 6 language mode, iOS 18 deployment target, SwiftUI, SwiftData, Swift Charts, CryptoKit, xcodegen 2.x, XCTest.

**Spec:** `docs/superpowers/specs/2026-09-05-hisab-design.md`

## Global Constraints

- Money is **integer paise** (`Int64`) everywhere; no floating-point currency.
- All calendar math uses `Calendar(identifier: .gregorian)` pinned to `TimeZone(identifier: "Asia/Kolkata")`.
- Amount display: Indian digit grouping, e.g. `₹1,23,456.78`; monospaced digits in UI.
- Palette tokens (exact): Khata Red `#A4243B`, Roshnai Ink `#22333B`, Kagaz Cream `#F5EFE6`, Sona Gold `#D9A441`, Hara Green `#3A7D44`.
- No third-party dependencies.
- Every `swift test` / `xcodebuild` run goes through `J=$(~/.claude/scripts/cpu-gate.sh)`; parallelism capped at `$J` (≤5).
- Git identity in this repo: `VedantS01 <vedantsaboo2001@gmail.com>`. Work happens on branch `feat/initial-build`; draft PR to `main` at the end.
- `samples/` is gitignored; tests use synthetic fixtures under `Tests/` only.
- Real parsers (GPay/Paytm/HDFC/IDFC) are **out of this plan** — a follow-up plan starts when files appear in `samples/`. This plan ships the parser protocol, detection registry, and one `SyntheticCSVParser` used by tests and demo data.

### Task 2: Domain types + content hash

**Files:**
- Create: `HisabCore/Sources/HisabCore/Domain.swift`, `ContentHash.swift`
- Test: `HisabCore/Tests/HisabCoreTests/DomainTests.swift`

**Interfaces (Produces):**
```swift
public enum SourceKind: String, Codable, Sendable { case paymentApp, bank }
public enum Source: String, Codable, CaseIterable, Sendable, Identifiable {
    case gpay, paytm, hdfc, idfc
    public var id: String { rawValue }
    public var displayName: String   // "Google Pay", "Paytm", "HDFC Bank", "IDFC First Bank"
    public var kind: SourceKind      // gpay/paytm → .paymentApp; hdfc/idfc → .bank
}
public enum Direction: String, Codable, Sendable { case debit, credit }
public struct DatePeriod: Codable, Sendable, Equatable {
    public let start: Date; public let end: Date   // inclusive
    public init(start: Date, end: Date)
    public var months: [YearMonth]                 // all IST months touched, ascending
}
public struct ParsedTransaction: Sendable, Equatable {
    public let date: Date
    public let amountPaise: Int64      // always positive; sign carried by direction
    public let direction: Direction
    public let counterparty: String
    public let reference: String?      // UPI/bank ref if the format carries one
    public let narration: String       // raw row text
    public init(date: Date, amountPaise: Int64, direction: Direction, counterparty: String, reference: String?, narration: String)
    public func contentHash(source: Source) -> String
}
```
`contentHash` = SHA256 hex of `"\(source.rawValue)|\(date as yyyy-MM-dd in IST)|\(amountPaise)|\(direction.rawValue)|\(reference ?? normalizedNarration)"`, where `normalizedNarration` = lowercased, whitespace runs collapsed to single spaces, trimmed.

**Steps:**
- [ ] Failing tests: period 2025-04-01…2026-03-31 → 12 months; single-day period → 1 month; hash stable across identical constructions; differs when reference differs; nil-reference fallback is case/whitespace-insensitive on narration.
- [ ] Implement → test → commit `feat(core): domain types and content hash`.

### Task 5: Reconciliation engine

**Files:**
- Create: `HisabCore/Sources/HisabCore/Reconciliation.swift`
- Test: `HisabCore/Tests/HisabCoreTests/ReconciliationTests.swift`

**Interfaces (Produces):**
```swift
public struct ReconTxn: Sendable {  // projection the app layer builds from stored transactions
    public let id: UUID; public let date: Date; public let amountPaise: Int64
    public let direction: Direction; public let reference: String?
    public init(id: UUID, date: Date, amountPaise: Int64, direction: Direction, reference: String?)
}
public enum MatchTier: String, Codable, Sendable { case reference, amountDate }
public struct MatchPair: Sendable, Equatable { public let appID: UUID; public let bankID: UUID; public let tier: MatchTier }
public struct ReconciliationResult: Sendable {
    public let matches: [MatchPair]
    public let appUnmatched: [UUID]
    public let bankOnly: [UUID]
}
public enum Reconciler {
    public static func reconcile(app: [ReconTxn], bank: [ReconTxn], dateWindowDays: Int = 2) -> ReconciliationResult
}
```
Algorithm: Tier 1 — index bank txns by non-nil reference; exact match consumes both sides. Tier 2 — remaining app txns in date order; candidates share `(amountPaise, direction)` within ±window days; pick smallest |date delta| (tie: earliest bank date); each bank txn consumed at most once.

**Steps:**
- [ ] Failing tests: reference match wins even 5 days apart; amount+date within window matches; outside window stays unmatched; two identical app txns vs one bank txn → exactly one matches; bank txn never consumed twice; bankOnly correct.
- [ ] Implement → test → commit `feat(core): tiered reconciliation`.

```swift
public struct ParsedDocument: Sendable {
    public let source: Source
    public let declaredPeriod: DatePeriod?   // nil when the format has no header period
    public let transactions: [ParsedTransaction]
    public var effectivePeriod: DatePeriod   // declaredPeriod ?? min…max txn dates
    public init(source: Source, declaredPeriod: DatePeriod?, transactions: [ParsedTransaction])
}
public enum ParseError: Error, Equatable { case unrecognizedFormat, passwordRequired, malformedRow(Int, String), empty }
public protocol StatementParser: Sendable {
    var source: Source { get }
    func canParse(data: Data, filename: String) -> Bool
    func parse(data: Data, password: String?) throws -> ParsedDocument
}
public struct ParserRegistry: Sendable {
    public init(parsers: [any StatementParser])
    public func detect(data: Data, filename: String) -> (any StatementParser)?  // first canParse hit
    public static var live: ParserRegistry  // currently [SyntheticCSVParser()]; real parsers appended in the follow-up plan
}
// SyntheticCSVParser: source .gpay. canParse: first line == "hisab-demo-csv,v1".
// Optional line 2 "period,yyyy-MM-dd,yyyy-MM-dd". Data rows:
// date(yyyy-MM-dd),amountPaise,debit|credit,counterparty,reference,narration  (reference may be empty)
```

**Steps:**
